**Тема:** Квота отчётов WB (20/сутки) исчерпывается ночным пакетом «Inventory report» — просьба помочь и предложение по координации

---

Коллеги, добрый день.

С 30 октября наш конвейер данных ежедневно не может выгрузить отчёты WB Analytics: дневная квота созданий (20 на продавца, сброс в 00:00 МСК) исчерпывается уже к ~01:35. По данным самого API, в 01:10–01:33 МСК создаётся пакет из 18 отчётов «Inventory report» — по одному на каждый из 18 прошлых дней. Данные воронки продаж не обновляются четвёртые сутки, дашборды работают на устаревших цифрах.

Полный разбор — факты, хронология квоты по минутам и способ самостоятельной проверки (одним читающим запросом, квоту не тратит) — во вложении (HTML, открывается офлайн).

Просьба:

- найти сервис, который запускает этот пакет, и перевести его на дельту — API штатно отдаёт остатки за период до 3 месяцев одним отчётом, то есть весь объём это 1 запрос вместо 18;
- либо перенести время запуска — удобное окно согласуем.

И предложение на будущее. Квоты и лимиты аккаунта продавца — общий ресурс для всех наших интеграций. Предлагаем заранее согласовывать друг с другом запуск и изменение расписания сервисов, работающих с WB API от нашего аккаунта: короткий анонс в общий канал до выката — и таких инцидентов не будет вовсе.
